# 软件更新状态栏进度：实现与定向验证

日期：2026-09-18（Asia/Shanghai）

## 结论与范围

- 分支：`feat/update-status-progress`；基线：已发布 v1.0.33，`355ec4b3434e929b89603bae0f844190ed6eac9b`。

## 交互

| 阶段 | 状态栏表现 |
| --- | --- |
| 连接更新源 | 阶段文字与不定进度动画 |
| 下载，响应提供有效总大小 | 实际已写入字节 / 总字节、整数百分比、确定进度条 |
| 下载，总大小未知或不可信 | 已下载大小与不定进度动画，不估算百分比 |
| 刷盘及 SHA-256 校验 | “正在校验更新…”与不定进度动画 |
| 校验通过 / 启动安装程序 | “正在启动安装程序…”与不定进度动画 |
| 安装进程运行、Pulse 仍存活 | “安装程序运行中…”与不定进度动画 |
| 取消、失败、结束或空闲 | 退出更新进度展示，保留原有错误通知机制 |

Pulse 退出后，安装进度由安装程序自身显示。没有跨进程安装百分比接口，因此不会把下载的 100% 冒充安装完成。

正常文件页和设置页共用该状态栏。搜索及其取消按钮优先，其次为活动文件操作，再次为更新；更新可替换已完成文件操作的摘要。点击更新进度不会打开文件操作窗口。设置卡片的下载文字也同步显示阶段或实际下载量，原有取消入口保留。

## 实现要点

下述源码路径均相对于隔离工作区。

- `src/app/update_transport.*`：新增兼容原有读取器签名的进度接口；读取最终 HTTPS 响应的 Content-Length；只在消费成功后累计字节。未知长度仍受 512 MiB 流式上限约束，已知超限长度提前拒绝。
- `src/app/update_installer.*`：工作线程与 UI 通过加锁快照传递阶段和计数；切换下载源时重置部分文件及计数；保留 HTTPS、取消、文件只读保护、重解析点检查和哈希校验。
- `src/app/update_progress.h`：百分比使用精确整数边界计算，避免浮点取整误差及大计数乘法溢出。
- `src/app/update_status.h`、`app_runtime.cpp`：统一文案、展示优先级和测试截图适配。
- `src/app/app_updates.cpp`：仅活动且窗口可见、未最小化时最多 10 Hz 刷新；不按网络分块投递窗口消息；启动安装程序前先绘制准备阶段。
- `src/ui/ui_renderer*`：复用现有进度组件、居中布局和窄宽度省略；更新状态使用普通状态栏命中区域，而不是文件操作入口。
- `src/common/{string_ids.h,localization.h,localization.cpp,strings.rcinc}`：中英文阶段文案及资源编号上界同步更新。
- `CMakeLists.txt`：新增默认关闭的 `PULSE_BUILD_PROGRESS_UI_TESTS`，用于构建真实应用视图模型/渲染器的隔离测试。
