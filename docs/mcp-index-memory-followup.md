## 结论与后续方向

CPU 没有复现持续高占用，但索引服务长期内存尚未证明得到明显降低，也未稳定在先前约 200 MiB；本轮还捕获到约 460 MiB 工作集 / 219 MiB 私有提交的波峰。此前微基准证明的是特定路径的临时分配减少，不代表整个服务长期内存问题已解决。

下一步若继续优化，应对服务的短时大额分配、合并后映射驻留、事件 feed 与历史路径保留分别取证，而非强制清工作集或再次仅凭重启后的低值评价效果。当前证据不足以认定具体根因，本轮不修改代码。
