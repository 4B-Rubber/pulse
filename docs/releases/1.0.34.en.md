- Sidebar sections can be reordered by dragging, have their own menus and show hints when collapsed; drop positions for pinned Quick Access items are more accurate, and OneDrive now has its own section.
- Fixed a missing "Open with", duplicate items and stale cache entries in the merged File Explorer context menu.
- Native previews for SVG, WMF and EMF, plus a preview switch in the details panel; the preview window follows drags better, and a stuck system preview handler no longer affects the files previewed after it.
- Downloading, verifying and launching an update now shows progress in the status bar: real progress when the download size is known, and no fake percentage when the size is unknown or during installation.
- Updated the LumaText text-rendering SDK and tuned the optical weight of regular text while keeping the intended look; release builds use an SDK rebuilt with the v143 static runtime.
- Upgrades keep the launch-at-startup and open-folders preferences while uninstalling still cleans up normally; added staging support for the runtime libraries needed by local development installers.

Installers are still available for Windows 10/11 x64 and Windows 8.1 x64.
