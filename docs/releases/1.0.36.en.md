- Fixed drag-to-reorder for sidebar tags: dragged tags did not move and the order was not saved.
- Fixed tab-group labels that could not be dragged or collapsed/expanded with a click; also fixed the drag state getting stuck, with the mouse never released, after dropping a collapsed group.
- The interface no longer freezes when copying, extracting or deleting many files in large folders. File-change notifications are now merged per folder and applied to the list in one pass: adding 3,000 files to a folder of 20,000 used to freeze the window for over 15 seconds, and it now stays responsive.
- Smoother list painting and hover: file-name layout measurements are cached, clearly reducing CPU use for hovering, scrolling and repainting in large folders.
- Sorting by Type no longer allocates memory for each comparison, so large folders sort faster.
- Lower idle power use: the window refreshes less often when minimized or hidden in the tray, and background index-service status updates no longer repaint the whole window; they refresh only when the search page, command palette or Settings is visible.
- The tab-group drag state is reset correctly when the window unexpectedly loses mouse capture.

Installers are still available for Windows 10/11 x64 and Windows 8.1 x64.
