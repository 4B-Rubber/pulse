# Pulse 1.0.30

本次发布包含自 1.0.14 以来的全部累积更新（1.0.15–1.0.30），各版本完整说明见仓库 `docs/releases/`。以下先概括主要新能力，再列出 1.0.30 相对已交付的 1.0.29 安装包的变化。

## 主要新能力（自 1.0.14）

- **文件名与内容实时搜索**：为本地文件夹建立实时索引，保存、删除、改名后结果自动更新；搜索栏「文件名 / 内容」一键切换，输入短延迟提交，中文组词完成后再查询。
- **拼音文件名搜索**：默认支持全拼、首字母、中英文数字混合及多音字匹配，直接匹配优先并高亮命中汉字；可在设置中关闭。
- **文档内容搜索**：支持 TXT、MD、LOG、CSV、JSON、XML 等文本与代码格式，以及 PDF、Word（DOCX）、Excel（XLSX）、PowerPoint（PPTX）；DOC、XLS、PPT、RTF 需系统文档筛选器。PDF 仅搜索可提取文字层，不做扫描图片 OCR。大文档有独立输入预算（默认 512 MiB），旧缓存升级后自动重新提取。
- **完整结果与流式浏览**：内容搜索不再止步 10,000 条，结果流式写入本地结果库并按页读取；排序、筛选、全选与跨页选择基于全局序号，滚动、拖动与选择在结果持续到达时保持可用；标题区分搜索中、完成总数与取消/不完整计数。
- **全局搜索**：新增可随时呼出的快速搜索弹窗——在设置中录制激活快捷键（支持冲突与无效检测），可搜文件名与内容，提供「全部位置 / 当前文件夹」范围与拼音开关，键盘操作（↑↓ 选择、Enter 打开、Ctrl+Enter 打开位置），首屏最多 200 条并提示精简关键词；跟随系统深浅色与材质背景，主程序关闭后仍可呼出，从托盘退出结束。
- **设置中心**：统一导航层级与分组布局，新增设置搜索、内容索引管理（目录、编码、排除规则、暂停/重建）与支持的文档类型说明。

## 1.0.30 相对 1.0.29 安装包

- **关闭后重开不再自动重扫**：修复关闭内容搜索窗口或标签后重新打开时自动发起新扫描的问题。恢复的界面只还原地址、关键词、空结果视图与「搜索已停止」状态；显式刷新或修改关键词（含相同关键词回车）才重新搜索。分屏恢复与窗口恢复共用同一入口，后台刷新与分页同样尊重停止状态。
- **修复搜索结束出现 1022 的状态混淆**：满队列先查重再判断溢出；订阅自动更新异常单独记录来源，已知积压先处理再暂停订阅，不再混入初扫错误状态，也不自动触发全盘重扫。界面显示「自动更新已暂停（结果已保留；刷新可获取最新变化）」，保留初扫命中、计数与完成状态；真实文档解析错误仍正常提示。
- **取消搜索**：内容搜索进行中提供「取消搜索 · Esc」操作，可随时停止当前搜索。
- **更新应用图标资源**，统一高分辨率图标。

## 验证与边界

- 关闭/重开修复：基于真实会话 JSON、窗口恢复与导航入口的 18 项定向检查通过。
- 1022 修复：40 项订阅缺口/协议/取消与订阅暂停的 UI 状态检查通过；上述 18 项会话恢复检查保持通过。
- 全局搜索：快捷键注册/冲突/释放 8 项检查通过；设置界面开关、快捷键录制命中区、文案宽度与 DPI 布局检查通过。
- 本地化：59 项字符串资源检查通过；主程序与索引服务以 1.0.30 版本资源构建。
- 发布由 GitHub Actions 在推送 v1.0.30 标签后构建 Windows 10/11 与 Windows 8.1 安装包，运行重命名生命周期、子编辑器、本地化、更新与索引引擎/主机压力等定向测试后发布。
- 内容搜索覆盖与时延结论来自本机隔离夹具及 52 个实际文件对照（52/52 提取匹配），不代表所有文件格式、磁盘或时延全面领先；不支持扫描图片文字识别。
