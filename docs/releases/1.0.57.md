### 本版说明

本版仍以 **上游 1.0.56** 为基线（未吸收新的上游内容），内容是本分支的一批修复与两个新选项。

### 修复

- **编辑文件名时光标跳回开头（回归）**：用输入法提交组字后，插入点被写回 0，后续字符插到最前面——`demo` 再打 `1` 变成 `1demo`。这套保护在 10 月初合并上游 1.0.53 的重建里整段丢失，本版补回：一轮提交后 2 秒内丢弃把插入点挪到提交位置之前的请求（点击、方向键、Home/End、退格/Delete、焦点变化结束这一轮），`WM_SETTEXT` 重写全文的路径也会恢复光标。
- **「仅空格预览」模式下空格没反应**：以前空格预览必须有选中项，切到该模式后把指针停在文件上按空格什么都不发生。现在没有选中项时，空格预览指针下那一行并选中它；已有选中项时仍然预览选中项，不会被指针抢走。
- **文件操作进度看起来像卡住**：进度以前只在状态栏那个胶囊里。现在可以选择用弹窗显示，见下方「新增设置」。

### 新增设置

- **进度显示在弹窗中**（设置 → 通用 → 文件列表组）：打开后复制/移动/删除会像 Windows 一样弹出进度窗口（不抢焦点，操作开始约 0.4 秒后出现，完成后自动关），**同一个操作不再同时出现在状态栏胶囊里**，那段空间还给选中项与提示文字。操作中手动关掉窗口时胶囊会回来接替，点它可重新打开窗口。默认关闭（保持状态栏）。
- **紧凑标题栏**（设置 → 外观）：隐藏标题栏左侧的 Pulse 品牌标识，把空间留给标签页；侧边栏折叠按钮**保留**并移到窗口最左边，Ctrl+B 也仍然有效。默认关闭。

### 其他

- 标题栏的主题按钮改为三态循环：跟随系统 → 浅色 → 深色 → 跟随系统，图标分别是半圆 / 太阳 / 月亮，悬停提示写明当前状态。以前点一下就会丢掉「跟随系统」，只能回设置里重新选。
- 「预览方式」里的「空格预览」改名为「仅空格预览」，说明文字同步更新，避免"选了却不能空格预览"的误解。

### 上游

本版未吸收新的上游内容，基线仍是 1.0.56。
