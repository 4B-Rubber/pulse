# Pulse 1.0.15 搜索增强

## 使用

- 文件名搜索默认支持全拼、首字母、中文/英文/数字混合及多音字匹配；直接匹配优先，命中汉字高亮。设置 → 搜索与索引可以关闭拼音搜索。
- 搜索栏的“文件名 / 内容”按钮切换模式；内容模式直接输入正文。输入采用短延迟更新，中文输入法组词时不提前查询。
- 设置 → 搜索与索引 → 管理内容索引，添加本地文件夹。每个文件夹可选择自动、UTF-8、系统编码或 GB18030，可移除目录、暂停/继续或重建。
- 默认排除 .git、node_modules、target、build、dist；管理菜单可分别切换。文本文件上限为 64 MiB，未加入索引的本地目录可由用户主动启动一次扫描。
- 内容索引保存在当前用户目录，由 Pulse.Index 后台处理；本版覆盖现有纯文本类型，不包含 Office、PDF、OCR 或网络正文索引。已有 content: 查询及保存的搜索入口保留。
- 默认按相关度显示；点击列标题可改为对应列排序，搜索选项可恢复相关度。

## 实际验证

- 内容索引：57 项通过，涵盖持久化、编码、取消、索引恢复及两个真实后台进程共享与接管。
- 原有内容/重复扫描独立夹具：55 项通过。
- 搜索解析、高亮及 DPI 布局：46 项通过。实际主界面流程另有 9 项通过，涵盖批次合并、选中项、滚动、过期结果、清空及同词重搜。
- 本地化测试通过，新增 34 条文案在中文和英文中均可读取。
- 中英文、明暗主题、100%/150%/200% DPI 截图检查完成；修复高 DPI 窄窗口提示文字重叠。
- 正式 Release 主程序及三个后台程序构建成功；内嵌自测关闭。
- 用正式文件清单和独立 AppId 验证安装、旧后台替换、保留非安装器文件、五个运行文件 SHA-256 一致、许可文件、安装后启动和卸载。未对用户现有安装执行服务注册、原位卸载/升级或数据清理回调。

## 性能

百万文件生产索引夹具：常见文件名查询热态 P95 为 47.03 ms，原始基线为 57.25 ms。独立 5% 中文百万条夹具拼音查询 P95 为 40.83 ms。500 万条容量及正确性验证通过，常见查询 P95 为 234.96 ms；100 ms 目标仅适用于百万条场景。

内容夹具为 10,240 个文件、约 1 GiB。最终后台默认排序首批 64 条 P95 为 10.28 ms，名称排序为 76.68 ms；稀有词、中文及空结果均低于 1.4 ms，满足首屏 200 ms 目标。遍历常见词全部 10,240 条约 1.30–1.35 秒，首屏时间不等于全量遍历时间。

独立新库建库资源样本为 10.55 秒、峰值工作集约 81 MiB。最终后台打开已有测试库并完成配置/对账的两次等待为 20.72 秒和 3.61 秒，未计入查询延迟。这些是本机夹具与热态测量，不代表系统冷缓存或每台机器的表现。没有完成 Everything GUI 的同条件对照；也不把亚毫秒查询的波动描述为所有查询均满足“退化不超过 10%”。
