### Quick Look and enhancement packs

- Added a dedicated Quick Look settings page for supported formats, system extensions, and four optional enhancement packs.
- The format overview distinguishes built-in support, enhancement packs, and system extensions, with collapsible categories and a layout that adapts to narrow windows.
- Media, modern image, RAW camera photo, and archive packs are available through Settings with this release. Media enhancement also supports an existing FFmpeg installation.
- Improved audio/video metadata reading and GIF thumbnail caching to reduce repeated work.
- Improved asynchronous document image loading and layout, added horizontal scrolling for wide Markdown tables, and improved result isolation when switching previews quickly.
- Files identified as text by Windows use the native text preview, avoiding unnecessary preview-handler startup.

### Folder sizes

- Separated displayed results from background calculation progress. Refreshing, cancelling, or deferring a calculation keeps the previous result visible, while progress and status appear in the tooltip.
- Reuse valid results to reduce repeated scans when returning to a folder. Improved scan budgets, cancellation, completion after scrolling out of view, and cache restoration; late index or scan replies cannot overwrite a newer request.
- Complete totals show the size without an `≈` prefix. Cached values and index estimates use muted text, with their source and verification status explained in the tooltip. Incomplete totals use `≥` to indicate a known lower bound.
- Tooltips use readable units such as KB, MB, and GB and adjust their position near the bottom of the window.

### Text input and the Open dialog

- Improved file operations, sidebar navigation, the address bar, and filename entry in the Open dialog.
- Unified text rendering, selection, and hit testing in input fields, retaining fallback handling and using a bounded layout cache to reduce repeated work.
- Fixed Traditional Chinese settings search and clipped wrapped descriptions.
- Fixed mismatches between the selection rectangle and selected items in column view.
- Fixed selection jumping to the first row after deleting files. Selection moves to the next surviving item, or the previous item when deleting the last row, including multiple selections and filtered views.
- Delete and restore operations show items processed per second and estimated time remaining.
- Hidden file icons appear faded, protected system items have a shield marker, and tag dots remain visible in the collapsed sidebar.

### Reliability

- Fixed moving a folder containing a locked file incorrectly requesting administrator permission. Pulse identifies the locking application and supports retrying after it is closed.
- Optimized name sorting in very large folders and reduced repeated enumeration when opening a folder.
- Fixed tray and session data validation, reference updates after file operations, overwriting damaged configuration files, and saved search paths.
- Improved search-condition handoff, NOT conditions, sorting across sources, and cancellation isolation for network searches.
- Fixed menu target identity, reuse of hidden panes, duplicating This PC tabs, and adding pinned tabs to groups.
- Improved directory watch recovery, enumeration, and network cache updates to reduce stale results after directory changes or connection interruptions.
- Fixed the Send to menu being disabled by slow-extension protection and clear incorrectly persisted disable states from older versions.

### Downloading enhancement packs

Install packs through **Settings → Quick Look**. You do not need to handle the `.lzms` release attachments or pack JSON manifests manually. All four packs reuse the previously validated 1.0.1 contents; this release updates their official download locations.
