- Fixed multi-selection in search results being cleared unexpectedly: any file change on the PC, or scrolling to the bottom to load more results, used to reduce the selection to a single item. All selected items and the focused item are now kept by full path.
- Fixed background refreshes selecting the first row when no search result was selected.
- Much lower CPU use while the search page is idle: the index service only pushes results when they actually change, instead of resending identical pages for unrelated file changes. Previously the UI process could use more than 25% CPU while idle on the search page.

Installers are still available for Windows 10/11 x64 and Windows 8.1 x64.
