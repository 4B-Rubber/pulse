### Search and navigation

- Fix a crash when content-search results appear by separating paged results from directory snapshots.

- Fix lost file selection when opening its location, and dismiss path editing when clicking outside the address bar.
- Add Advanced Search to search options with Ctrl+Shift+F, preserving the current draft and scope.
- Show folder sizes in Details view and filename-search results using the existing index and background calculation. Network folders remain on demand.
- Fix blank-area double-click navigation requiring an extra click when items are selected.
