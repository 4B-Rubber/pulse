# Pulse 1.0.26 测试版

本版本用于实测实时搜索重构，不代表完整发布验收已经完成。

## 本次改动

- 正文结果存储读写稳定身份，改名/覆盖更新保持身份；修复增量排序与过滤请求互相取消的问题。
- 统一 Unicode 名称及扩展名排序，过滤后继续保持当前排序。
- 共用索引的隔离端到端测试已接通，并增加连接、查询、发布和退出诊断。
- 索引合并失败增加退避，避免在每次监听循环反复重写。
- 补齐空卷快照末尾长度，发布前校验新快照；保留旧映射直至新文件发布成功，并在失败时尝试回滚。
- 修复主机关闭时先等待写锁、后取消写入的阻塞顺序，关闭信号可中断通信等待。

## 建议实测

1. 直接升级安装，保留现有设置和索引；不需要卸载或手动清理缓存。
2. 搜索一个文件名，依次新建、改名、移入子目录、删除，观察结果是否自动更新。
3. 搜索正文关键词，保存含该词的文本，再移除关键词和删除文件，观察列表变化。
4. 切换排序与过滤，尝试改名后继续选择、双窗格搜索和快速切换关键词。
5. 退出再打开 Pulse，确认索引能够继续使用。

反馈请注明操作步骤、文件类型、等待时间，以及是否需要手动刷新。异常日志位于 `%LOCALAPPDATA%\Pulse`。
