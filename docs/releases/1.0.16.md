# Pulse 1.0.16 搜索交互优化

按确认的设计实现：范围选择、文件名/内容双选、输入框和独立搜索选项。

- 文件名与内容一键切换，保留输入文字；中文组词完成后再提交查询。
- 右侧选项菜单显示拼音开关、相关度勾选及独立的内容索引管理入口。
- 历史记录对齐输入区域，标注范围与模式；清空操作弱化显示。
- 内容结果提示栏提供“管理索引”快捷入口。
- 窄窗口优先保证模式标签完整；更窄时使用图标与提示，范围可从选项菜单进入。

验证：16 项实际界面流程检查、46 项搜索/布局检查及中英文本地化测试通过。检查了中英文、明暗主题和 100%/150%/200% DPI，修复本次新增控件的截断与提示栏重叠。正式构建无新增编译警告，内嵌自测关闭。

本次未改动搜索后端算法；未重复运行上一版的后端性能测试，也未安装或替换用户当前服务。

证据：bench_data/search-segments/ 下的 flow-test.log、layout-test.log、localization-test.log、release-zh.png、release-en-narrow.png、options-final.png、history-final.png。

安装包：dist/PulseSetup-1.0.16.exe；同目录提供 SHA-256 校验文件。
