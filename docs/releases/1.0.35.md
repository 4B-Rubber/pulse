# Pulse 1.0.35

## 自动更新可以关掉了

「设置 → 通用 → 自动检查更新」关闭后，Pulse 不再联网检查新版本，也不会弹出安装提示；如果当时正在下载，下载会停止。「关于与诊断」里的手动检查同样会被拦住，所以关掉之后不会再有后台网络请求。

## dev 频道

本仓库发布的是 dev 频道，从这个版本起在名字上就能看出来：

- 安装包名为 `PulseSetup-1.0.35-dev.exe`（Windows 8.1 兼容版为 `PulseSetup-1.0.35-dev-win81.exe`）；
- 「设置 → 关于与诊断」里显示的版本带 `-dev` 后缀，文件版本号仍是数字；
- 更新源指向本仓库的发布页，更新清单由本仓库自己的密钥签名。

dev 包与稳定版共用同一套安装身份（安装目录、注册表、数据目录）：安装它会覆盖稳定版，并沿用现有的设置与窗口会话。

## 界面

- 每个目录可以单独记住视图设置（排序、分组、隐藏项等），切换目录时不再互相覆盖。
- 图标条与工具栏的按钮支持悬停提示，出现前的等待时间可以在「设置 → 通用」里选择。
