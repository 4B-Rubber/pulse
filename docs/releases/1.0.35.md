- 新增多窗口：可以再开一个独立进程的窗口（`--new-window`，标签菜单与托盘菜单里也能直接开），标签可以在窗口之间拖动——拖到另一个窗口就成为它的标签，拖到别处则变成独立窗口；最后一个标签离开时窗口关闭，托盘图标、全局热键与会话交接给接收它的窗口。新窗口按指定目录打开；多个窗口各有标签但共用设置，快速访问、最近、收藏、工作区、索引排除项与标签组的改动不再互相覆盖。
- 每个目录单独记住自己的视图：视图模式、排序方式与详情栏列宽按目录保存（`folder-views.json`，按最近使用保留 500 条）。
- 侧栏与详情面板改为按窗口大小自适应：拖动分栏以文件列表的最小宽度为界，宽窗口不再被固定的 480 dip 上限卡住；窗口最小宽度从 640 降到 320 dip。
- 新增悬停提示（图标条、工具栏、设置行、列表行与折叠栏）与提示延迟设置（150 / 400 / 800 毫秒，或 50–5000 毫秒自定义）。
- 右键菜单新增复制文件 SHA-256 / MD5（后台计算，结果直接进剪贴板）与解除下载锁定（去掉让 Windows 标记「已阻止」的 Internet 标记）。
- 新增缩略图缓存设置页（占用大小与一键清理）；缓存与应用共用一个用户数据目录，并与预览进程共享。
- 界面细节：选中颜色更深、隐藏文件在列表中淡显、标题栏图标与名称可以关闭；标签组有真正的分组标识；运行中切换系统主题立即跟随；最近与收藏菜单支持「在文件夹中显示」；框选随列表滚动同步；悬停高亮不再在星标行下渗色。
- 修复输入法用整段重写的方式提交组词后光标跑到文本最前的问题（重命名框里输入 "demo" 再敲 "1" 不会变成 "1demo"），并修复提示延迟预设点选后不立即生效、哈希计算任务在窗口关闭时未取消（会让退出时进程终止）、被替换的哈希任务可能把 MD5 标成 SHA-256 的问题。
- 稳定性：最后一个标签关闭时窗口正确关闭、设置不再被回滚、接管 Directory / Drive / Folder 类型的「打开文件夹」行为。
- 新增「设置 → 通用 → 自动检查更新」开关（默认开）：关闭后不再联网检查、不再弹出安装提示，正在进行的下载会停止，手动检查与提示点击同样被拦住。
- 本仓库发布的是 dev 频道：安装包名为 `PulseSetup-1.0.35-dev.exe`（Windows 8.1 兼容版为 `PulseSetup-1.0.35-dev-win81.exe`），界面显示的版本带 `-dev` 后缀，更新源指向本仓库发布页并由本仓库自己的密钥签名。dev 包与稳定版共用同一套安装身份，安装会覆盖稳定版并保留现有设置与会话。

继续提供 Windows 10/11 x64 和 Windows 8.1 x64 两种安装包（均属 dev 频道，安装包名带 `-dev` 后缀）。
