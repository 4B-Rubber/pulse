# Pulse 1.0.35

这一版的主题是：多窗口、每个目录自己的视图、更顺手的界面细节，以及本仓库自己的 dev 更新频道。

## 多窗口

- 可以开第二个窗口：它作为独立进程启动（`--new-window`，标签菜单与托盘菜单里也能直接开），不再被单实例限制吞掉。新窗口按你指定的目录打开，不再从主窗口的位置开始。
- 标签可以在窗口之间拖动：拖到另一个 Pulse 窗口就成为它的标签（即使那个窗口已经打开着同一目录），拖到没有窗口的地方则变成一个独立窗口；最后一个标签离开时窗口关闭，托盘图标、全局热键与会话交接给接收它的窗口。
- 多个窗口各有自己的标签，但共用设置：快速访问、最近、收藏、工作区、索引排除项与标签组的改动不再互相覆盖。
- 移动窗口时详情预览会跟着走（原来会滞后）。

## 目录与视图

- **每个目录单独记住视图**：视图模式、排序方式、详情栏列宽按目录保存（`folder-views.json`，按最近使用保留 500 条）。
- **侧栏与详情面板按窗口大小自适应**：拖动分栏以文件列表的最小宽度为界，宽窗口不再被固定的 480 dip 上限卡住；窗口最小宽度从 640 降到 320 dip，可以窄到只剩侧栏和文件列表。
- **悬停提示**：图标条、工具栏、设置行、列表行与折叠栏都会显示名称，出现前的等待可选（150 / 400 / 800 毫秒，或 50–5000 毫秒自定义）。

## 界面与手感

- 选中颜色更深，隐藏文件在列表里淡显；标题栏是否显示图标与名称可以开关。
- 标签组有了真正的分组标识；侧边栏与托盘显示的内容做了精简。
- 运行中切换系统主题会立即跟随，不用重启。
- 最近与收藏菜单支持「在文件夹中显示」。
- 框选（橡皮筋）随列表滚动同步；悬停高亮不再在星标行下渗色。
- 输入法用整段重写的方式提交组词后，光标不再跑到文本最前：重命名框里输入 "demo" 再敲 "1" 不会变成 "1demo"。

## 右键菜单与缓存

- 右键菜单可以复制文件的 **SHA-256 / MD5**：在后台计算，结果直接进剪贴板（可以在设置里关掉这个子菜单）。
- 右键菜单可以**解除下载锁定**，去掉让 Windows 把文件标为「已阻止」的 Internet 标记。
- 新增**缩略图缓存设置页**：查看占用大小、一键清理；缓存与应用共用一个用户数据目录，并与预览进程共享。

## 稳定性

- 最后一个标签关闭时窗口会正确关闭；设置不再被回滚。
- 接管 Directory / Drive / Folder 类型的「打开文件夹」行为。
- 提示延迟的预设点选后立即生效并关闭内联编辑。
- 哈希计算任务在窗口关闭时被取消（此前会让退出时进程终止）；被替换的任务不会把摘要交给下一个任务（此前可能把 MD5 标成 SHA-256）。

## dev 频道与自动更新

- 本仓库发布的是 **dev 频道**：安装包名与「设置 → 关于与诊断」里显示的版本带 `-dev` 后缀（`PulseSetup-1.0.35-dev.exe`，Windows 8.1 兼容版为 `PulseSetup-1.0.35-dev-win81.exe`），而 `version.txt`、文件版本号与更新清单里的版本号仍是数字。
- 更新源指向本仓库的发布页，更新清单由本仓库自己的密钥签名。dev 包与稳定版共用同一套安装身份（安装目录、注册表、数据目录）：安装它会覆盖稳定版，并沿用现有的设置与窗口会话。
- 新开关：**设置 → 通用 → 自动检查更新**（默认开）。关闭后不再联网检查、不再弹出安装提示，正在进行的下载会停止；「关于与诊断」里的手动检查与提示点击同样被拦住。

## 文档

- 更新：自动更新与发布、设置落盘（安装器捕获与应用侧的职责划分）、重命名验证（输入法一节）。
