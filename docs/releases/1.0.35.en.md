- Right-click → Properties on multiple files now opens a combined Properties window showing the file/folder count and total size, just like File Explorer; this also works for multiple items in the Recycle Bin.
- Fixed Alt+Enter not opening the Properties window (the shortcut was already shown in the menu).
- With multiple items selected, the status bar shows their total size; for content-search results it appears once the background total is ready. The selected size is cached per selection, so selecting all of a large result set does not slow down painting.
- Fixed caches that depend on the selection sometimes not refreshing after a marquee selection.
- The frame rate in the debug status bar now counts frames actually painted in about the last second, instead of showing idle gaps as very low frame rates or two nearby repaints as an abnormally high one.

Installers are still available for Windows 10/11 x64 and Windows 8.1 x64.
