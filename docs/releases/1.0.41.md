这条线从上游 1.0.38–1.0.40 合并而来：除了下面的自研修复，还一次带来了上游这段时间的全部功能与性能改动。

随合并并入的功能
- 分栏浏览：同时显示上级目录、当前目录与选中的文件夹，列宽可调，支持键盘导航。
- 空格预览新增视频播放：播放 / 暂停 / 定位 / 逐帧，GIF 支持进度拖动与逐帧；媒体调用全部在 UI 线程之外，拖动响应更快。
- 详细信息视图改版：列宽按内容实测自适应（语言、字体、DPI、日期格式），窄窗格按「类型 → 日期」隐藏次要列并在悬停提示里补齐，路径中间省略、智能日期、斑马纹、类型列彩色扩展名标签、大小列右对齐；设置里新增三个开关（智能日期 / 斑马纹行 / 大小比例条）。
- 多选「属性」打开合并属性窗口（文件与文件夹数量、总大小），Alt+Enter 同样可打开；状态栏显示所选项目的总大小。
- 内容搜索实时更新后仍按完整路径锁定选中项；搜索结果空闲时重复推送整页结果的行为被去掉（此前搜索页空闲占用 25% 以上 CPU）。
- 文件变化通知按文件夹合并：两万文件的目录里新增三千文件时的十几秒卡顿消失。
- 侧栏「标签」改为彩色 Fluent 图标；标签的拖拽排序、分组折叠与拖放不再卡住。
- 打包改为静态 MSVC 运行库：安装目录不再需要随包携带运行库 DLL，安装器会清掉旧版本留下的那一份。

本仓库的自研修复
- 标签拖出成新窗口（或拖进另一个窗口）时，新窗口会还原原来的选中项——真实目录按文件名、最近使用 / 收藏 / 标签 / 搜索按完整路径——详情预览跟着同一个文件，而不是落到第一行。
- 「最近使用 / 收藏 / 标签」这类视图现在跟随文件本身：文件被修改后大小与类型会更新，被改名或删除后显示为「不可用」。重读在原列表上就地完成，选中项、滚动位置与预览不跳动；列表里有网络路径时只在窗口回到前台时重读，避免每次后台检查都吃一次网络超时。
- 设置页三个列表开关（智能日期 / 斑马纹行 / 大小比例条）此前点了没有反应，现已接到正确的开关编号。
- 修复预览偶发以很小的尺寸打开：面板折叠或窗口缩放还没结束时，预览提供程序只排版一次并保留缩放；现在等预览矩形稳定后再打开，最多等待 400 毫秒。

本仓库发布的是 dev 频道：安装包名为 `PulseSetup-1.0.41-dev.exe`（Windows 8.1 兼容版为 `PulseSetup-1.0.41-dev-win81.exe`），界面显示的版本带 `-dev` 后缀，更新源指向本仓库发布页并由本仓库自己的密钥签名。dev 包与稳定版共用同一套安装身份，安装会覆盖稳定版并保留现有设置与会话。

继续提供 Windows 10/11 x64 和 Windows 8.1 x64 两种安装包（均属 dev 频道，安装包名带 `-dev` 后缀）。
