## Interface and file display

- Merged #5: the sidebar and details panel adapt to the window width, keeping room for the file list when the window gets smaller.
- Fixed double scaling of the sidebar at high DPI found while integrating the panels, with regression coverage at 100%, 125%, 150% and 200%.
- Merged #6: a separate "Show protected operating system files" option, off by default and controlled independently of ordinary hidden files, with updated preference persistence and selection behavior.

## Background indexing and resource use

- Unneeded change-history UI polling stops while the main window is hidden or minimized.
- Improved change-history aggregation, serialization and change-stream storage, reducing unneeded allocations and history copies.
- Fixed USN queue capacity accounting and backpressure handling.
- Name-pool garbage is now compacted locally instead of triggering a full index merge on its own; necessary structural merges and history persistence are kept.
- Temporary performance timers, memory sampling and JSONL diagnostic logs are off by default, with explicit diagnostic switches kept.

## Release validation

- The release process adds targeted regression checks for panels, hidden files, history, USN, the name pool and diagnostics being off by default.
- Installers and matching signed update manifests are provided for Windows 10/11 x64 and Windows 8.1 x64.

This release does not claim to fix all short-query latency or momentary memory peaks from history snapshots.
