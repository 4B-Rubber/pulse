# Pulse 1.0.25

- Content searches process file change notifications directly instead of rescanning all configured folders for each save or deletion. Brief save locks are retried, and active crawls service pending file changes.
- Search-result renaming uses the list's shared layout, including the search filter bar. Automatic content refresh waits until renaming finishes.

Validation: isolated add/change/delete, nested rename, move-out and locked-save checks passed. In a 4,000-file fixture, three runs measured 0.77–1.48 seconds from saving an Excel file to its result appearing, and 0.78–1.50 seconds from deletion to removal. Rename geometry and cancellation checks passed at 100% and 150% scaling. Installed-app visual verification remains for user testing.
