本版是一次完整的上游同步：dev 合并了上游 1.0.42 的全部内容（上游 1.0.41 与 1.0.42 两版的改动此前一直没吸收，这次一并进来），本仓库自己的修复全部保留。

版本号说明：本版是 dev 自己发布线的下一号（上一版 1.0.42）。**本版包含上游 1.0.41 / 1.0.42 的内容**——上游与本仓库的版本号是同号不同源，看到 1.0.43 不是跳过了一版。

上游内容（本次合并吸收）
- 视图切换形变动画：列表在详情/图标/平铺等视图之间切换时，条目从原来位置移动到新位置（两遍绘制：先形状后文字），切换不再是一瞬间的跳变。
- 侧栏折叠按钮与标题栏重排：标题栏加入侧栏折叠开关（折叠后停在导轨上并替代品牌标记），品牌名与应用简介按可用宽度实测摆放。
- 定时器节拍自适应：有动画或交互时跟随显示刷新率，窗口静止、最小化或隐藏到托盘时自动降到低频轮询（长时间挂着的空闲占用更低）。
- 预览扩展：新增/增强了一批预览类型，并支持按内容识别扩展名不可信的文件（`.bak`、`.vsix`、`.rtf` 存成 `.bak`、字体备份等）——识别不出才回落十六进制。
- 「关于」页可以离线查看最近几个版本的发布说明。

本仓库保留的行为
- 每文件夹视图记忆、列宽记忆（拖动结束与双击自适应都保存）、按「访问」而不是「改动」排序的淘汰顺序。
- 列表选择细节：空选择时方向键/翻页键落在首行（向上则在末行），双击空白处返回上一级不再需要三次点击。
- 文件名按单版式着色绘制（扩展名稍淡、长中文名不再被截断），隐藏项在列表里变暗，与资源管理器的观感一致。
- 文字清晰档：LumaText 不做栅格重采样、轮廓贴像素网格，覆盖率 gamma 不再抬亮（暗色主题保留轻微补偿）。
- 「隐藏标题栏标记」开关仍然有效：关掉后标题栏只留标签条。
- 命令面板筛选框键入选字后立即重新呈现（粘贴、输入法合成结束同样处理），呈现失败回落控件自绘。

发布信息
- 本仓库发布的是 dev 频道：安装包名为 `PulseSetup-1.0.43-dev.exe`（Windows 8.1 兼容版为 `PulseSetup-1.0.43-dev-win81.exe`），界面显示的版本带 `-dev` 后缀，更新源指向本仓库发布页并由本仓库自己的密钥签名。dev 包与稳定版共用同一套安装身份，安装会覆盖稳定版并保留现有设置与会话。
