这条线建立在上一次合并（上游 1.0.38–1.0.40）之后的增量上：本版没有新的上游合并，全部是本仓库自己的修复。

本仓库的修复
- 「每文件夹视图记忆」补全：列视图（分栏）布局现在随文件夹一起记忆；「此电脑」也参与记忆（它的路径为空，此前被整体跳过）；一个窗口自己指定的视图（恢复工作区、`--view`）会写进该文件夹的记忆，不会再在加载瞬间被旧记忆改回去。
- 列宽现在真的记得住：此前保存点写在「鼠标移动时发现按钮已弹起」的分支里，而按钮抬起消息更早被处理并清掉了状态，那个分支从不执行。现在拖动结束与双击列分隔线自适应都会保存。
- 记忆的淘汰顺序改为按「访问」而不是按「上次改动」：进入文件夹即刷新时间戳（会话自动保存时落盘），常看但不改设置的文件夹不会再被 500 条上限裁掉。
- 列表选择细节：列表里没有任何选中项时，第一次按方向键 / 翻页键落在第一行（向上则最后一行），不再多走一行；有选中项时双击空白处返回上一级不再需要三次点击（上游 issue #25 报的就是这个）。
- 命令面板的筛选框由合成器绘制，键入选字后会立即重新呈现（粘贴、输入法合成结束同样处理）；呈现失败时回落到控件自绘，不会再出现「打了字但框里是空的」。

发布信息
- 本仓库发布的是 dev 频道：安装包名为 `PulseSetup-1.0.43-dev.exe`（Windows 8.1 兼容版为 `PulseSetup-1.0.43-dev-win81.exe`），界面显示的版本带 `-dev` 后缀，更新源指向本仓库发布页并由本仓库自己的密钥签名。dev 包与稳定版共用同一套安装身份，安装会覆盖稳定版并保留现有设置与会话。
- 继续提供 Windows 10/11 x64 和 Windows 8.1 x64 两种安装包（均属 dev 频道，安装包名带 `-dev` 后缀）。
