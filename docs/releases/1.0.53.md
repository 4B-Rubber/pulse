### 快速预览与增强包

- 设置新增统一的「快速预览」页面，集中展示支持格式、系统扩展及四种预览增强包。
- 格式按内置、增强包、增强包或系统扩展区分；分类说明与格式标签分栏，支持展开收起和窄窗口布局。
- 媒体、现代图像、RAW 相机照片、压缩包增强包与本版一同发布，可在设置中下载；媒体增强也支持使用已有 FFmpeg。
- 改进音视频属性读取和 GIF 缩略图缓存，减少重复处理。
- 改进文档图片的异步加载与布局，支持 Markdown 宽表格横向滚动，完善快速切换预览时的结果隔离。
- 对系统标记为文本的文件优先使用内置文本预览，减少不必要的预览组件启动。

### 文件夹大小

- 将已显示的统计结果与后台计算进度分开：刷新、取消或暂缓计算时保留上次结果，进度与状态放在悬停提示中。
- 复用仍有效的结果，减少返回目录时的重复扫描；改进扫描预算、取消、离屏完成和缓存恢复，防止迟到的索引或扫描回包覆盖新请求。
- 完整统计直接显示大小，不加 `≈`；缓存值和索引估算以较淡文字显示，悬停可查看来源与核验状态。有遗漏的统计以 `≥` 标明已知下限。
- 提示中的大小统一使用 KB、MB、GB 等易读单位，靠近窗口底部时自动调整提示位置。

### 输入与打开对话框

- 完善打开对话框的文件操作、侧边栏、地址栏和文件名输入体验。
- 输入框统一文字呈现、选区和命中，保留故障回退；有界布局缓存减少重复计算。
- 修复繁体中文设置搜索和说明文字换行裁切。
- 修复分栏视图框选区域与实际选中项不一致的问题。
- 修复删除文件后选中项跳回列表首项的问题；优先选中相邻的剩余文件，删除末项时选中前一项，并兼顾多选与筛选视图。
- 删除与还原操作显示每秒处理项目数及预计剩余时间。
- 隐藏文件图标以淡色显示，受保护的系统项目增加盾牌标记；侧栏收起时仍可看到标签色点。

### 稳定性

- 修复移动包含被占用文件的文件夹时误请求管理员权限的问题，正确显示占用程序并支持关闭后重试。
- 优化超大目录的名称排序，减少打开目录时重复枚举，降低大量文件场景下的等待时间。
- 修复托盘与会话数据校验、文件操作后引用同步、损坏配置覆盖及保存搜索路径问题。
- 改进搜索条件移交、NOT 条件、跨来源排序和网络搜索取消隔离。
- 修复菜单目标身份、隐藏窗格复用、复制此电脑标签和固定标签入组问题。
- 改进目录监听恢复、文件枚举和网络缓存更新，减少目录变化或连接中断后的陈旧结果。
- 修复「发送到」菜单被慢扩展保护误停用的问题，并清理旧版本留下的误停用状态。

### 增强包下载

请在「设置 → 快速预览」中安装增强包；无需手动处理发布附件中的 `.lzms` 文件和增强包 JSON 清单。四个增强包沿用已验证的 1.0.1 内容，本版更新其正式下载位置。
