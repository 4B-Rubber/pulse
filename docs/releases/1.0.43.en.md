This release is a full upstream sync: dev now carries everything from upstream 1.0.42 (both upstream 1.0.41 and 1.0.42 had been waiting for a merge), and every fix from this repository is kept.

Version note: this is the next number on dev's own release line (previous release: 1.0.42). **This release does include upstream 1.0.41 / 1.0.42.** Upstream and this fork share number ranges but not contents, so 1.0.43 does not skip a release.

From upstream
- View transitions: rows travel from their previous position to the new layout when the view mode changes (drawn in two passes, shapes then labels).
- Sidebar collapse toggle in the title bar, standing in for the product mark on the rail, with the app name and description laid out against the measured width.
- Adaptive timer pacing: the display rate while anything animates or responds, gentle polling once the window is quiet, minimized or hidden to the tray.
- More preview coverage plus content sniffing for files whose extension says nothing (`.bak`, `.vsix`, RTF saved as `.bak`, font backups and more); only unrecognised content falls back to hex.
- Settings > About can show the release notes of the last few versions offline.

Kept from this repository
- Per-folder view memory, column widths that survive (saved on drag end and on double-click auto-fit), and eviction by visit rather than by last change.
- List selection details: the first arrow/page key with nothing selected lands on the first row (the last row when pointing up), and double-clicking empty space goes back without needing three clicks.
- File names shaded in one layout (extension a step dimmer, long CJK names no longer clipped), hidden entries dimmed the way Explorer does.
- The crisp text profile: no raster resampling, hinted outlines, no coverage gamma lift (dark theme keeps a slight compensation).
- The "hide title bar mark" switch still works: the title bar keeps just the tab strip.
- The command palette's filter field repaints as you type (and after paste or IME composition), with a native fallback if presenting fails.

Release notes
- This is the dev channel: the installer is `PulseSetup-1.0.43-dev.exe` (`PulseSetup-1.0.43-dev-win81.exe` for Windows 8.1), the UI shows the `-dev` suffix, updates come from this repository's releases and are signed with its own key. The dev build shares the stable install identity, so installing over the stable build keeps your settings and session.
- Both Windows 10/11 x64 and Windows 8.1 x64 installers continue to ship (both on the dev channel, both with the `-dev` suffix).
