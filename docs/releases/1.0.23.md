# Pulse 1.0.23

- Fix content-history searches being cancelled before execution: cancellation now invalidates the current request without inventing the next caller-owned request ID. Repeated cancel/navigation followed by an adjacent request no longer produces a false zero-result completion that waits for an index-status change to retry.
- Indexed content search publishes the first hit immediately. Subsequent hits remain batched, with periodic progress/partial-result updates while processing candidates. Existing FTS matching, ordering, result limits and cached document extraction are unchanged.
- Pending content queries display the localized searching title; progress without hits does not present a completed zero-result count. Arriving results remain selectable while the query continues.
- Search result path, date modified, type and size center vertically in the whole row. The shared metadata renderer derives its bounds from the row; the content filename and snippet retain their two-line layout. The DirectWrite fallback explicitly centers paragraphs and restores format state.

Validation:

- Built only the affected main app, content agent and focused content-index test target; no full build or legacy suite.
- The old code failed six targeted assertions, including adjacent/repeated/rapid cancellation returning ERROR_CANCELLED with zero hits. The final focused content test passes 15 checks, including first-hit delivery, all 256 matches for the two-character query `20`, sorting, truncation, cancellation after the first hit and explicit transient scanning through the shared client.
- In the isolated 256-document fixture, the four persistent-client requests completed in 15–16 ms. This measures this fixture only, not the user's complete index or cold-disk performance.
- Actual mouse selection from the history menu, single request submission, editor restoration, pending/progress/partial/final/empty states, selecting the first arriving row and rejecting stale completions pass in dark 150% and light 100%. Native render snapshots of these five states were captured and inspected. The compositor snapshots omit the separately hosted native edit text while it is focused; the query chip and header remain visible.
- The scoped exit regression passes, including delayed-submit cancellation, stale results, exact local/virtual source restoration, IME Escape, history fallback and per-tab network-source model checks.
- The column-alignment fixture generated paired filename/content screenshots across dark/light themes, 100/150/200% scaling and 36/40/48 DIP row heights. All 18 metadata-region pixel comparisons are identical, including selected rows and a content row without a snippet.
- Existing uncommitted changes retained. No content database migration, document-extraction dependency or full reindex is required.
