# Pulse 1.0.17

## Settings

- Unified the settings navigation and page hierarchy, with constrained content width, grouped controls and responsive layouts.
- Added settings search that opens the matching page, expands advanced options and scrolls to the selected setting.
- Added persistent Light / Dark / System appearance choices and retained the existing animated accent color wheel.
- Replaced window-effect and language radio lists with dropdowns. Density and staging-tray size use short segmented labels, fixing the reported text overlap.
- Grouped startup and file-list preferences; retained wallpaper, folder-opening integration, hidden files, pinned names, empty-area double-click and change tracking in More options.
- Added inline content-index folders, count summary, per-folder status and menus, pause/resume, exclusions and rebuild actions. Filename-index storage, drives, excluded paths and network folders remain under Storage & maintenance.
- Made context-menu groups expandable independently of their enable switches. Reused the same grouped surface for duplicate scan controls; About & diagnostics remains pinned in the sidebar.
- Filename, content and options controls in the search bar use the arrow cursor; the query input uses the text cursor.

## Verification

- Targeted settings flow passed: actual theme/density/pinyin clicks, theme JSON migration and round trips, search filtering, scroll clamping, color-wheel hit target, context group hit targets, and navigation across four window widths at 100%, 150% and 200% scaling.
- Measured Chinese and English density/tray labels against the segment widths to reproduce and prevent the reported overlap.
- Targeted interaction checks passed using temporary content folders and an isolated profile: live folder status, missing-folder error, pause/resume, keyboard selection in language/material menus, per-folder encoding/removal, exclusions, and typing into settings search to reveal an advanced option.
- Inspected actual screenshots of all five pages, light/dark themes, English/Chinese, compact navigation, advanced options, high DPI and populated/paused/error content-index states.
- Only the affected application and installer component targets were built. The full legacy self-test suite was not run. File dialogs and system integration actions retain their existing implementations; tests did not change the user's files, index configuration or registry integration.
