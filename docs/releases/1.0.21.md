# Pulse 1.0.21

- Current content-search batches release the retained-results interaction lock immediately, allowing selection and scrollbar dragging while further results arrive. Progress-only updates keep old rows pending; completion and empty results clear that state.
- Vertical scrollbar dragging now uses the same list origin, row height, filter/banner offsets and thumb sizing as rendering.
- The original mouse grip stays on the scrollbar when the result count changes during a drag. Scrollbar presses use the clicked pane's view model.

Validation: focused real input-handler regressions passed at 100% dark and 150% light scaling, covering arriving content rows, mouse selection, three thumb grip points, drag/release, results appended during a drag, filename search without snippets, stale/progress-only updates and empty completion. Inspected both search-mode screenshots. No new compiler warnings; no full legacy test suite was run.
