# Pulse 1.0.18

- Settings now use the available window width with fixed page padding, removing the large centered gutters on wide displays.
- All five context-menu groups start expanded. Users can still collapse individual groups without changing their enable switches.
- Switch outlines align to device pixels and scale their thickness with DPI. Corrected the rounded outline radius and centered the thumb on the resulting track.

Validation: the focused width/default-expansion regression passed at 760, 1280 and 3045 logical pixels across 100%, 125%, 150% and 200% scaling. Verified shared navigation hit targets, manual collapse/reopen and unchanged group preferences. Rendered and inspected off/on/hover/disabled switches at all four scales, plus actual wide dark and narrow light settings screenshots. The affected application and installer component targets were built; the full legacy test suite was not run.
