1.0.60 测试版 · 2026-11-10。本版由 dev 分支构建：基于 1.0.60 正式版（2026-11-10），包含其全部改动，另加 dev 分支的以下增量。

### 压缩

- [新功能] 压缩支持选择容器格式（ZIP、7Z、TAR.GZ）与压缩强度（存储、快速、标准、最大），默认 ZIP + 标准；生成的文件名跟随所选格式。
- [改进] 压缩进度在操作窗口中显示：正在处理的文件（文件 N/M）、已处理的字节和本次峰值速度；压缩任务的进度文字不再误用「已传输」。

### 文件操作与进度

- [新设置] 操作进度窗口可以自动弹出：操作开始约半秒后出现，结束后很快隐藏；任务期间手动关闭后本次不再打扰。
- [改进] 进度窗口实时显示传输速率。
- [修复] 等待冲突处理时不再弹出进度窗口；进度窗口不再挡住状态栏胶囊提示。

### 安装与升级

- [改进] 旧版本目录被第三方程序占用时，安装器不再要求退出应用，而是把删除延期到下次重启，静默完成升级；Pulse 自身进程占用时仍会提示。
- [修复] 升级中断后的恢复遇到被占用的 DLL 不再报「拒绝访问」：先改名腾位，恢复完成后延期删除。
- [修复] 索引服务镜像路径读不到时改从服务管理器取进程号；清理前先结束索引宿主进程，必要时用调试特权重试删除。

### Pulse 助手

- [新功能] 文件可以直接送入输入框，让助手引用处理。
- [改进] 助手面板可以拖动调整大小：停靠面板拖右缘，悬浮卡片拖上缘；删除会话后自动切换到相邻会话。
- [改进] 模型菜单改用 Fluent 菜单，并显示模型自述的介绍。

### 设置与外观

- [新设置] 紧凑标题栏：隐藏 Pulse 品牌区，侧栏开关移到窗口边缘，标签栏从左缘开始。
- [新设置] 侧栏暂存托盘可以关闭；隐藏时也不再往里暂存。
- [改进] 主题按钮在「跟随系统、浅色、深色」之间循环，图标直接显示当前状态（半圆、太阳、月亮）。
- [改进] 空格预览在未选中时以悬停行为目标，关闭悬停卡片后空格键不再失效；选项更名为「仅空格」。
- [修复] 全局搜索热键与页面范围开关的校验。

### 浏览与 Shell 集成

- [改进] 大文件夹边读边显示：就绪的行先出现，读取完成后补齐排序与详情树；回收站、此电脑等 Shell 命名空间在长枚举期间保持完整。
- [改进] 「打开/保存」对话框的跳转条改为驱动原生地址栏（按 Windows 版本适配结构），Enter 不再误触发「保存/打开」按钮。
- [改进] 回收站删除的撤销还原到 Shell 实际生成的项目：父目录是 junction、同一名字多次回收也能还原正确的那一份。
- [改进] 分组卡片恢复：悬停卡片用统一几何绘制，鼠标离开或调整窗口大小时收起；分组的激活记忆跨重启保留。
- [修复] 恢复输入法组合期间的光标保护（1.0.53 重建时丢失），连续输入保持顺序、光标不跳位。
- [修复] OneDrive 不再在侧栏列出两次，命名与资源管理器一致。
- [修复] Win+E 不再每次启动都拉起提权 broker。
- [修复] 从外部请求（如跳转条）启动时直接打开目标位置，而不是恢复上次会话。
- [修复] Shell 文件夹退役的右键动词全部释放，不再只释放「打开」。

---

以下为 1.0.60 正式版（2026-11-10）的内容，本版同样包含：

本次更新集中修复 1.0.59 的目录加载、文件操作、标签栏和窗口交互问题，建议使用 1.0.59 的用户升级。

### 目录与文件操作

- 修复部分磁盘或文件夹打开时长时间等待的问题：列出文件不再探测快捷方式的网络目标，其余链接解析也不会无限拖住目录显示。
- 修复按修改日期、大小排序时，同名覆盖或文件内容更新后仍停留在旧位置的问题；更新排序时保留文件的选中身份。
- 修复 Ctrl+拖动文件到当前目录不能创建副本的问题；连续复制生成不同副本，原文件保持不变。
- 解压、复制、移动和压缩后的结果选择更准确：优先选中实际产物并使其可见，不把临时目录或无关新文件当作结果。
- 修复重新选中压缩包再次解压后仍选中压缩包的问题；多个操作同时完成时保留各自结果，用户中途手动选择其他文件后不再抢回选择。

### 标签栏与窗口

- 恢复标签栏滚轮浏览，支持水平滚轮；标签过多时保留可读标题，通过滚动查看其余标签。
- 滚到最左或最右时隐藏对应箭头并禁用点击，保留布局占位，避免标签位置跳动。
- 改进新窗口首帧显示和窗口位置记忆，完善贴靠窗口的位置恢复。
- 完善多级右键菜单、屏幕边缘展开方向和键盘导航。

### 预览与系统集成

- 图片快速预览改用异步尺寸探测，改善快速切换和关闭时的响应。
- 改善返回文件夹时缩略图的连续显示，并限制预览工作线程和照片墙缓存的占用。
- 完善替代打开／保存对话框的自定义控件、分隔线、默认扩展名和兼容处理。
- 完善安装程序关闭与重新启动 Pulse 的处理，以及桌面入口启动行为。

### 扩展与开发预览

- 完善扩展商店浏览、已安装扩展管理，以及插件生成文件的发布和结果定位。
- 更新原生插件 SDK 的对话框接口和界面模型；开发预览插件仍需按对应 SDK 编译，商店可用内容取决于在线目录。

### 升级说明

- 本版是 1.0.59 的修复更新，沿用三段版本号，兼容现有客户端的自动更新检查。启用自动检查后，客户端会在启动约 15 秒后或持续运行每 6 小时检查新版。
- 安装包仍分为 Windows 10/11 x64 和 Windows 8.1 x64 兼容版。
- 新版发布并校验更新清单后，将撤下问题较多的 1.0.59 Release；已安装用户请升级到本版。
