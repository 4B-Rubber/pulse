- 「删除到回收站 / 彻底删除 / 从回收站还原」这三类由 Shell 完成的操作现在显示「项/秒」速度与预计剩余时间；复制、移动与清空回收站仍按字节显示。Shell 只对删除和还原回报条目数，此前这些任务没有可用的速度读数，速度区的单位现在完全由任务类型决定（当前速度、峰值与历史曲线用同一单位）。
- 修复 Pulse 运行期间系统光标反复闪出「正在启动」蓝色圆环的问题：网络索引代理此前会被每秒重新创建一次，每次创建都会让系统把指针切成带圆环的形态，在桌面、任务栏与其他程序上都看得到；现在不再出现。
- 网络索引代理改为按需启动：只有在配置了服务器目录时才随 Pulse 启动，未配置时整个会话都不会创建该进程（在「设置 → 搜索与索引」添加第一个服务器目录时按需拉起）；代理只服务于启动它的那个 Pulse 窗口，Pulse 退出（含异常退出）时随之结束，不再残留常驻进程。
- 本仓库发布的是 dev 频道：安装包名为 `PulseSetup-1.0.37-dev.exe`（Windows 8.1 兼容版为 `PulseSetup-1.0.37-dev-win81.exe`），界面显示的版本带 `-dev` 后缀，更新源指向本仓库发布页并由本仓库自己的密钥签名。dev 包与稳定版共用同一套安装身份，安装会覆盖稳定版并保留现有设置与会话。

继续提供 Windows 10/11 x64 和 Windows 8.1 x64 两种安装包（均属 dev 频道，安装包名带 `-dev` 后缀）。
