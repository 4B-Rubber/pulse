# Pulse 1.0.22

- Filename matches use translucent amber rounded backgrounds, fine outlines and theme-aware text. Dark mode adds a subtle glow. Each match has 2 DIP of horizontal padding on both sides; matching characters retain their internal letter spacing.
- Name measurement, ellipsis fitting, tag placement and row-action hit testing account for the padding. The same highlight treatment is used in list and icon views.
- Explicit search exit cancels pending input and rejects late results before restoring the source address. Escape in the search editor follows the exit button; IME composition and open menus retain first priority. Losing editor focus still leaves results open.
- Source addresses are captured centrally when entering search and stored with individual navigation history entries, including repeated queries from different locations. Missing history metadata falls back to the nearest non-search address, including virtual pages.

Validation: the original code reproduced six failures in targeted exit/history checks. The repaired checks pass at 100% dark and 150% light, including real mouse exit, editor Escape, IME, pending input, content/name late results, empty results, virtual origins, repeated-query history and a removed directory. UNC source capture and independent tab history were checked at model level; no live network-share round trip was exercised.

The focused highlight suite passed and generated 42 screenshots across dark/light, 100/150/200 percent scaling, list/icon layouts, narrow columns, selected rows, contrast wallpaper and Chinese pinyin matches. Inspected representative renders in every scale, both themes, narrow lists and icon views. Width checks cover padding and stable ellipsis fitting. Only the affected main application was rebuilt; no full legacy suite was run.
