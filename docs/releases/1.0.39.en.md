- Details view columns now size to their content: Date, Type and Size are measured for the current language, font, scaling and date format instead of using fixed widths, and the space saved goes to the file name. Columns you resized keep their width; double-click a column divider to return to automatic sizing.
- When a pane gets narrow, secondary columns hide automatically in the order Type, then Date, so file names stay readable. Hidden information (modified time, the folder of a search result) appears in the hover tooltip.
- In narrow search-result panes, results switch to two lines with the folder path below the file name instead of being squeezed and cut off.
- Paths are shortened in the middle, keeping the drive and the last folders (for example "C:\…\boost\regex"); long names and types end with an ellipsis instead of being cut abruptly.
- New smart dates: recent times read "Today 14:32", "Yesterday 09:10" or "Wed 18:00", dates this year show month and day with time, and older items show only the date.
- New zebra rows: alternating rows in Details view get a faint tint, making wide lists easier to follow.
- Colored extension chips (EXE, DLL, PDF, ZIP and more, colored by category) in front of the Type column; the extension in the file name is slightly dimmed so the name itself stands out.
- Size values are right-aligned with units in their own column, so KB and MB line up for easy comparison.
- Search highlights now use a light accent background with an underline, softer than the previous amber outline.
- Settings → Appearance adds Smart dates, Zebra rows and Size bars switches; the first two are on by default, size bars are off.

Installers are still available for Windows 10/11 x64 and Windows 8.1 x64.
