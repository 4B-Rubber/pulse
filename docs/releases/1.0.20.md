# Pulse 1.0.20

- Storage & maintenance starts expanded, while retaining manual collapse/reopen.
- Search results cap Date modified, Type and Size at compact DPI-scaled widths. Surplus width from restored column ratios is returned to Name and Path; their divider remains adjustable.
- Search options and content-index management share a continuous focus guard. Management stays anchored below the search toolbar, and the inline content-management button no longer dismisses the search editor.

Validation: focused column checks passed for default/restored layouts at 500, 800, 1440 and 2400 logical pixels with 100%, 125%, 150% and 200% scaling, including name/path divider dragging. Verified storage default expansion and manual collapse/reopen. Inspected dark/light rendered column and settings screenshots. Mouse menu selection, menu dismissal, query/location preservation, inline management and restoration of a pre-existing focus guard passed. Built affected targets and packaged the release; the full legacy test suite was not run.
