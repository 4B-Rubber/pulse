## 简介
Pulse —— 为 Windows 打造的文件管理器，让浏览、搜索和整理文件更顺手。

✦ 索引搜索：NTFS 全盘索引（MFT / USN），实时更新；支持类型、日期、大小组合筛选，也能搜索文件内容
✦ 全局搜索：关闭主窗口后 Alt + Space 随时呼出；支持拼音全拼、首字母与中英混合
✦ 即时预览：选中文件按空格即可预览图片、PDF、视频和文本
✦ 多窗格 + 标签页：并排处理多个目录，彩色标签、暂存区、重复文件查找
✦ 个性外观：浅色 / 深色一键切换，Acrylic / Mica 材质，自定义壁纸与强调色
✦ 原生性能：C++20 · Win32 · Direct2D · DirectComposition，索引、预览、Shell 任务独立运行不卡界面
✦ 自动更新：加速源自动切换，签名与安装包双重校验
✦ 兼容：Windows 10 / 11（64 位），另有 Windows 8.1 兼容版
